# review-repo-health — source & influences

Queued in `learning/INBOX.md` from 2026-07 and built 2026-08-16. Every seed in the skill is a class found by hand during a one-off full-repo pass of `agentic` in 2026-07: a doc pointing elsewhere for content that wasn't there, a structure doc missing a folder that existed, an entry doc that never said what the thing was, one discipline duplicated across an always-loaded doc and a skill, and two adjacent sections whose relationship a reader couldn't infer.

The open-ended framing is deliberate and predates the build: a fixed checklist gets walked mechanically, and the findings that mattered in 2026-07 were noticed, not enumerated. The seeds exist to start the pass, not to bound it — which is also why the skill can propose its own seeds, on the same what-does-a-reader-gain test it ranks findings by.

Two boundaries were decided before the skill existed. Checking an *in-flight* proposal against its target file belongs to `propose-shared-change` (2026-07-30) — this skill audits the repo as it stands. Credentials and identifying data belong to `review-repo-security`; both are standalone sessions for the same reason, and the session-size evidence behind that rule is recorded in that skill's README.
